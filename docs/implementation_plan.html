質量分析 (MS) パック 実装計画

Bruker micrOTOF の測定(.d)を ProteoWizard の msconvert で自動的に mzML に変換して読み込み、TIC から時間範囲を選んだ平均スペクトルを作り、組成式から計算した同位体パターンを重ねて ppm 誤差を出すプラグインの計画です。仕様はユーザーと合意済みで、実データ(mzML)の中身だけが確認待ちです。

決まった仕様(v1.0)

項目決定
読み込み変更パネルで .d フォルダを選ぶと、プラグインが ProteoWizard の msconvert を別プロセスで実行して mzML に変換し(画面は止めない)、読み込む。変換した mzML はプラグインの保存フォルダにキャッシュし、同じ .d は2回目から変換しない。ProteoWizard は最初に1回インストールするだけで、測定ごとの手作業の変換は要らない。mzML を直接開くこともできる。mzML は XML・base64・zlib を標準ライブラリと numpy で解釈する(pyteomics は使わない)。
操作画面ドックパネル(タブごとに1つ、フロートすれば独立ウィンドウとしても使える)。複数の mzML を一覧に開いて切り替えられるので、正負のファイルを並べて比べられる。
時間範囲の選択パネル内の TIC をドラッグして選び、開始・終了の数値欄と連動させる。
背景の差し引きv1.0 に入れる。「試料」と「背景」の2つの時間範囲の平均の差を作る。負の値を 0 にするかを選べる。
ファイルを開く / ドロップimporter は、スキャンが1つならそのスペクトル、複数なら TIC を返す。スペクトルの切り出しはパネルで行う。
照合の入口analyzer「同位体パターンと照合」(選択中の実測スペクトルに対して実行し、表・重ね描き・注釈を返す)と、パネルの「組成式から計算」欄(実測なしでも計算できる)。
付加イオン正の標準([M+H]+ [M+Na]+ [M+K]+ [M+NH4]+ [M]+•)、負の標準([M−H]− [M+Cl]− [M]−• [M+HCOO]−)、または [2M+Na]+, [M+2H]2+, [M−H−H2O]− のような表記の入力。表記を解釈するので、ユーザー定義・多量体・2価以上も扱える。重ねるのは実測に見つかった付加イオンだけで、表には全部出す。
線幅(分解能)ガウスの FWHM = m/z ÷ R。R の欄が 0 なら実測の最も強い同位体ピークの半値全幅から求め、使った値を表に出す。
追加するスペクトル平均した profile を線で追加。任意で、プラグインが求めた centroid を棒(Stick)で追加。計算パターンは線と棒の両方。

追加の要件(2026-09-28)

マウスのドラッグ操作を充実させるパネル内の TIC とスペクトルに、範囲選択・拡大・パン・測定・範囲の伸縮と移動を持たせる(下の「マウス操作」)。
ピークに数値を表示するパネルのスペクトルでは表示範囲の主なピークに m/z を自動で表示。本体のプロットに送ったデータセットにもラベルを付ける。
表示桁数を変えられるm/z の小数点以下の桁数(既定 4)、強度の表し方、ppm の桁数をパネルで設定。パネルの表示・送ったラベル・表に効く。
プロットに転送するTIC、平均スペクトル(背景差し引き後を含む)、centroid、計算パターンを、ボタンと右クリックメニューから本体のプロットに追加する(Undo 可)。

本体のプロット(メイン画面の軸)には、プラグインからマウス操作を足す拡張点がありません。ドラッグ操作はパネル内のグラフで行い、結果を本体に転送する形にします。本体のプロットでは、本体にもともとあるホイール拡大・中ボタンのパン・範囲選択モードがそのまま使えます。

ピークのラベルと桁数

場所付け方
パネルのスペクトル表示範囲の中で強い順に N 本(既定 10、「相対強度 X% 以上」にも切り替え可)。拡大すると範囲の中で選び直すので、拡大するほど細かいピークにもラベルが付く。近すぎるラベルは強い方を残す。クリックで固定したピークは常に表示。
本体のプロット送る centroid の Stick データセットに文字列のラベル列を持たせ、本体の「点のラベル」(show_point_labels と point_label_col_name)で表示する。ラベルを付けるのはパネルと同じ規則で選んだピークだけで、ほかの行は空文字(本体は空のラベルを描かない)。
profile だけに付けたいとき「ピークラベルだけを転送」: 同じ Stick データセットを線なし(線種「なし」)で送る。Stick の描画は線種が「なし」なら棒を描かず、本体がラベルだけを描く。
analyzer の結果付加イオンごとに、基準ピークの位置へ「[M+H]+ 523.2451 (−1.2 ppm)」の text 注釈を付ける。表の数値は桁を丸めずに持つ(CSV で精度を落とさない)。
桁数の設定m/z の小数点以下の桁数(0〜6、既定 4)、強度の表し方(なし / 相対 % / 絶対値の指数表記)、ppm の小数点以下の桁数(既定 1)。パネルの設定とラベル列の文字列に使う。analyzer ではフォームの「m/z の桁数」。

本体の点のラベルは、文字の大きさ(8 pt)と位置(点の右上)が固定で、色はデータセットの色です。データセットの点数が本体の上限(環境設定、既定 1000 点)を超えるとラベルは描かれないので、ラベル付きのデータセットはピークだけに絞って送ります。profile(数万点)にはラベルを直接付けられません。

本体の制約と対処

制約対処
すべて GUI スレッドで同期実行される最初はスキャンの見出し(時刻・TIC)だけを読み、配列は選んだ範囲の分だけ復号する。実データで 1 秒を超えるなら、パネルの中で QThread を使って読み込み、進み具合を表示する(ctx の呼び出しは GUI スレッドだけ)。
importer は DataFrame を1つだけ返し、フォルダは開けない主な入口はパネル(.d フォルダはパネルから選ぶ)。importer は mzML だけを受け、TIC か1本のスペクトルを返す。
プラグインは本体に同梱のパッケージしか使えず、.baf は非公開形式変換は利用者が入れた ProteoWizard の msconvert に任せる(プラグインは何も同梱しない)。msconvert は数秒〜数十秒かかりうるので、QProcess で別プロセスとして動かし、終わったら GUI スレッドで読み込む。
本体のプロットにマウス操作を足せない、注釈を ctx から足せない操作はパネル内のグラフ、本体のラベルは点のラベル(ラベル列)で出す。analyzer の結果だけは注釈を返せる。
param_schema の choice は登録時に固定付加イオンは「標準セット」の choice と、表記を書く文字列欄の組み合わせにする。
点のラベルは既定 1000 点までのデータセットにしか描かれないラベル付きで送るのはピーク(centroid)に絞ったデータセットだけ。

v1.0 に入れないもの

  • .d の直接読み込み(Bruker の baf2sql を ctypes で呼ぶ方法)。次の版の候補。
  • m/z からの組成式の推定(候補の列挙)、フラグメント解析。
  • LC-MS の netCDF(ANDI-MS)。P-108 で扱う。
  • ユーザーの測定データをテストデータとして公開リポジトリに入れること。テストは合成した mzML だけで行う。
