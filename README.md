# graphica-plugin-mass-spec

[Graphica](https://github.com/STsuruga/Graphica) 用の質量分析 (MS) パック(P-316)。Windows と macOS で動きます。

## できること

- Bruker の `.d` フォルダ(`analysis.baf`)を**そのまま開く**。ProteoWizard などの変換ソフトは要りません
  (確かめた装置は micrOTOF。対応していない圧縮方式の測定は、ProteoWizard の msconvert があれば自動で変換して開きます)
- mzML も開ける(MS ビューアからでも、Graphica の「ファイルを開く」・ドラッグ&ドロップからでも)
- MS ビューア: 左に開いた測定の一覧、右に3段(TIC、選んだ時間範囲の平均スペクトル、比較用の枠)。背景の範囲の平均を差し引ける
- ピークに m/z のラベル(表示範囲でいちばん強いピークに対する割合で出すかを決める。同位体でまとまるシグナルは代表の1本)
- 組成式からモノアイソトピック質量・平均分子量・同位体パターン・付加イオンの m/z を計算し、実測と照合して ppm 誤差と相対強度を比べる
- TIC・スペクトル・centroid・ピークのラベル・計算パターンを Graphica のプロットへ転送
- 棒(Stick)表示の種類

## 使い方

プラグイン ▸ **MS ビューアを開く** でウィンドウを開きます(クイックアクセスツールバーにピン留めするとボタン1つで開けます)。
ビューアの ファイル ▸ **.d を開く** で測定を開き、TIC をドラッグして時間範囲を選ぶと、2段目にその範囲の平均スペクトルが出ます。

| 場所 | 操作 | 動作 |
|---|---|---|
| 測定の一覧 | チェック / 名前をクリック | その測定の TIC の表示 / 2段目の対象にする |
| TIC | 左ドラッグ / Shift+左ドラッグ | 試料 / 背景の時間範囲 |
| TIC | 帯の端・帯の中をドラッグ | 範囲を伸縮・移動 |
| TIC | クリック | その時刻の1スキャン |
| スペクトル | 左ドラッグ | その m/z 範囲に拡大 |
| スペクトル | Ctrl+左ドラッグ | 矩形で拡大 |
| スペクトル | Shift+左ドラッグ | Δm/z と ppm を測る(同位体の間隔なら電荷数も) |
| スペクトル | ピークをクリック | ラベルを固定 / 解除 |
| スペクトル | 右クリック | 3段目の枠にコピー、プロットへ転送など |
| 軸の上 | ホイール / 左ドラッグ | その軸の拡大縮小 / 表示範囲をずらす |
| グラフの中 | ホイール(Shift で縦)/ 中ボタンドラッグ | 拡大縮小 / パン |
| 共通 | ダブルクリック / Backspace | 全体 / 1つ前の表示 |

3段目の枠の数と、枠どうしで横軸をそろえるかは、3段目の下で切り替えます。
時間範囲を数値で合わせるときは 表示 ▸ 時間範囲の詳細設定、ラベルの割合・桁数などは 表示 ▸ 表示設定 です。

照合は、ビューアの 解析 ▸ **同位体パターンの照合**(ビューアの2段目のスペクトルが対象)か、本体で実測スペクトルのデータセットを選んで
プラグイン ▸ 解析 ▸ 同位体パターンと照合 で行います。付加イオンは標準のセット
(正: [M+H]+ [M+Na]+ [M+K]+ [M+NH4]+ [M]+•、負: [M−H]− [M+Cl]− [M]−• [M+HCOO]−)に、
`[2M+Na]+, [M+2H]2+, [M-H-H2O]-` のような表記を足せます。計算パターンの線幅は、半値全幅(m/z の単位、既定 0.1)で指定します。

本体のプロットに送ったピークのラベルは、本体の「点のラベル」機能で表示されます(点数が本体の上限、既定 1000 点を超えるデータセットには描かれないので、ラベル付きで送るのはピークだけです)。
棒を描かずラベルだけにしたいときは「ラベルだけ」で送るか、本体で Stick のデータセットの線の太さを 0 にします。

## `.d` の読み込みについて

`analysis.baf` のデータを、このプラグインが自分で読みます(標準ライブラリと numpy だけ)。Bruker のプログラムやライブラリは使わず、改変もしません。
Bruker micrOTOF(APCI、m/z 50〜3000)の測定3件で、ProteoWizard の msconvert が出す値と、強度は全点一致、m/z は 0.03 ppm 以内で一致することを確かめています。
開くのは一瞬で(TIC は見出しから読む)、スペクトルは選んだ範囲の分だけ解きます(1スキャン 10〜60 ms)。

ファイルに書かれた圧縮方式が違う測定(ほかの機種など)は、[ProteoWizard](https://proteowizard.sourceforge.io/download.html) の msconvert が
インストールされていれば、自動で mzML に変換して開きます(Windows のみ。変換結果はキャッシュ)。ProteoWizard はこのプラグインに含まれていません。
各自でインストールし、ダウンロード時に示されるベンダーのライセンスに同意してください。
自分で変換する場合は `msconvert <.d> --mzML --zlib`(profile のまま、m/z は 64 bit、zlib 圧縮)にしてください。
**numpress 圧縮と peakPicking は使わないでください**(numpress は読めません。peakPicking をすると profile が失われます)。

## 開発環境

```
python -m venv .venv
.venv\Scripts\activate
pip install "graphica-plot>=2.0,<3"
pip install -r requirements-dev.txt
pytest
```

テストは合成したデータ(合成した mzML と BAF)だけを使います。

## zip のビルド

```
python scripts/build_zip.py --all      # dist/mass_spec-<version>.zip
```

Graphica の 編集 ▸ 環境設定 ▸「プラグイン」タブ ▸ プラグインをインストール... から入れます。
